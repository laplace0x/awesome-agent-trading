Frequently asked questions

What is agent trading?

AI agents can research markets, call tools, propose decisions, or execute orders under configured controls. Research-only tools and live systems have different capabilities.

Where should I start for US equities and options?

Explore Alpaca MCP for paper/live tools, Robinhood Agentic Trading for an eligible dedicated account, and Lumibot for Python backtesting and broker execution. Account and data requirements vary.

Are these skills limited to OpenClaw?

No. The directory covers MCP servers, CLIs, SDKs, and skills for the clients documented by each project.

Can AI agents trade on Polymarket or Kalshi?

Tools include Polymarket CLI, Simmer SDK, Kalshi Trading Bot CLI, and community MCP integrations. Check venue eligibility and simulated versus real-order support.
